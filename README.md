🏙️ NYC Airbnb Price Prediction Using Machine Learning

<p align="center">
  <strong>Exploratory Data Analysis | Machine Learning | Regression | Price Prediction</strong>
</p>📌 Project Overview

This project focuses on analysing New York City Airbnb listings and developing a Machine Learning model to predict listing prices based on relevant property and location-related features.

The project combines Exploratory Data Analysis (EDA), data preprocessing, feature engineering, and regression modelling to understand the NYC rental market and estimate Airbnb prices.

The objective is to transform raw Airbnb listing data into meaningful insights and build a predictive model using Python and Machine Learning techniques.

🎯 Project Objectives

- Analyse Airbnb listings across New York City.
- Understand pricing patterns across different neighborhoods.
- Explore relationships between listing features and prices.
- Perform data cleaning and preprocessing.
- Apply feature engineering to improve model inputs.
- Train regression models for price prediction.
- Evaluate and compare model performance.

🚀 Key Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Missing-value handling
- Feature engineering
- Neighborhood and room-type analysis
- Data visualization
- Machine Learning regression
- Airbnb price prediction
- Model performance evaluation
